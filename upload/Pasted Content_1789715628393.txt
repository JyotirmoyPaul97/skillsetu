============================================================
PRIMARY OBJECTIVE
============================================================

Build the INSTITUTION PORTAL as an institution-wide intelligence and decision-support system.

The Institution Portal must NOT be:

- a generic admin dashboard
- a student management system
- a simple placement dashboard
- a collection of charts
- a duplicate of Academia

It must answer:

1. What skills do our students currently demonstrate?
2. What skills does industry demand?
3. Where are the largest skill gaps?
4. Which branches / programs are affected?
5. What evidence supports those findings?
6. Which students/cohorts need intervention?
7. What intervention should the institution consider?
8. Which internships/projects/hackathons are contributing practical exposure?
9. Is the institution improving over time?
10. Which industry relationships can help close the gap?

CORE INSTITUTION LOOP:

STUDENT EVIDENCE
→ AGGREGATED SKILL INTELLIGENCE
→ DEMAND VS SUPPLY
→ BRANCH / PROGRAM GAP
→ PRIORITY
→ INTERVENTION
→ INDUSTRY / ACADEMIA ACTION
→ PARTICIPATION
→ NEW EVIDENCE
→ UPDATED INSTITUTIONAL INTELLIGENCE
