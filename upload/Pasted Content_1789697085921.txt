19. READINESS CALCULATION
============================================================

Formula:

Role Readiness =
SUM(Student Competency × Role Importance)
/
SUM(Role Importance)

Example Data Scientist:

Python 82 × 25% = 20.50

SQL 64 × 15% = 9.60

Statistics 51 × 20% = 10.20

Machine Learning 43 × 30% = 12.90

Problem Solving 75 × 10% = 7.50

Total:
60.70%

Displayed:
61%

The calculated value and displayed value must ALWAYS come from the SAME calculation.

Never hardcode:

Calculated:
9

Displayed:
76.6
