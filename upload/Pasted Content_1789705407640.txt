5. COMPETENCY MODEL
============================================================

Every student skill must have:

skillId
skillName
competencyScore
evidenceConfidence
lastUpdated
evidenceCount

Score range:

0–100

Competency means:

"What the system currently estimates the student can demonstrate."

Evidence Confidence means:

"How strongly the currently available evidence supports the competency estimate."

These are NOT the same thing.

Example:

Machine Learning

Competency:
43 / 100

Evidence Confidence:
Limited / 58%

Do not present Evidence Confidence as scientifically validated.

For this prototype it is a transparent supporting metric.
